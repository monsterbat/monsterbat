### What this GitHub is

My portfolio. The repos here are tools and side projects I built for myself and then
cleaned up enough to share. Most of my day-to-day code lives in private repos, so the
contribution graph is busier than the list below.

| Project | What it does |
|---|---|
| [**mindmap**](https://github.com/monsterbat/mindmap) | One mind map, four views: structure, task board, day planner, and what is left per topic. A human drags nodes in the browser; an AI edits the same JSON from the command line |
| [**photo-review**](https://github.com/monsterbat/photo-review) | Triage a 70,000-photo library: scroll, rate and tag with one keystroke, then write the result back into Darktable sidecar files |
| [**Optical_Metrology_Tools**](https://github.com/monsterbat/Optical_Metrology_Tools) | Desktop app for measurement data analysis: Ppk/Cpk, best-fit distribution, box plots, correlation, JMP script generation |
| [**score-player**](https://github.com/monsterbat/score-player) | Single-file HTML player for Guitar Pro and MusicXML scores, with a built-in synthesizer and guitar/saxophone fingering charts |
| [**video-maker**](https://github.com/monsterbat/video-maker) | Turns a folder of clips and a short brief into a finished video, all from one YAML file |
| [**image-shrink**](https://github.com/monsterbat/image-shrink) | Shrink photos below a target file size in the browser, no upload and no server |
| [**Food Chosen**](https://github.com/monsterbat/food_chsoen) | Group ordering and bill-splitting web app. Flask, MySQL, vanilla JS, Docker on AWS EC2 |
